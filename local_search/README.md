# OpenSAC Local Search

Independent dense local-search service for OpenSAC. See the repository-level
[`docs/local-search.md`](../docs/local-search.md) for setup and usage.

```bash
./local_search/run setup
./local_search/run prepare
./local_search/run
```

The setup command uses standard-library `venv` and pip; uv is not required.
