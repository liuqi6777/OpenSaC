from opensac_sdk import sdk

queries = [
  "Search as Code agents",
  "programmatic retrieval",
]

results = sdk.search.many(queries)
evidence = sdk.search.fuse_rrf(results)

for hit in evidence[:8]:
  text = sdk.content.fetch(hit.source)
  if "agent" in text.lower():
    sdk.state.append_jsonl(
      "evidence.jsonl", hit
    )

sdk.output.submit({"evidence": evidence})

01 / Thesis

The core idea

Retrieval should be a programming problem, not a prompt bottleneck.

A fixed tool interface forces the model to expose every intermediate step to its own context. OpenSAC moves orchestration into generated code, where queries can be batched, documents filtered, candidates fused, and state persisted before the useful evidence returns to the control model.

∞

Flexible composition with a deliberately small, inspectable capability surface.

From intent to evidence

One program.
A complete research pass.

The agent writes the strategy. OpenSAC executes it inside a hardened boundary and returns only what the program explicitly submits.

The research question

When the model, retrieval backend, and evaluation protocol are held constant, does composing search primitives in generated code improve quality, context efficiency, or the latency–cost trade-off over model-visible tool calls?

OpenSAC is the controlled runtime built to investigate that question.
